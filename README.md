# Sataya Fieldbook

Справочник существ ARK: Survival Evolved и Survival Ascended с инструкциями по приручению и личной коллекцией.

[Открыть справочник](https://satayalib.github.io/sataya_dino/)

## Возможности

- Каталог ASE/ASA и DLC, включая варианты ARK Additions и Paleo ARK.
- Поиск, фильтры, избранное и список планируемых приручений.
- Коллекция дино: снимки очков до и после приручения, прокачка, мутации, импринт и заметки.
- Добавление вручную или по скриншоту на русском и английском языках.
- Сравнение до четырёх дино.
- Импорт и экспорт CSV, полные резервные копии JSON.
- Работа без сети, светлая и тёмная темы, мобильный интерфейс.

Коллекция хранится в браузере. Для переноса между устройствами используйте CSV или JSON. Скриншоты обрабатываются локально; распознанные значения можно исправить перед сохранением.

Распознавание поддерживает текстовые подписи и панели с иконками, колонками и полосами статов. Для общих портретов нужно подтвердить разновидность существа. Статы из метки имени и текущей панели сохраняются раздельно.

## Разработка

Стек: Rust, Yew, WebAssembly, IndexedDB и Tesseract.js.

Нужны Node.js 22+, Rust 1.99.1 и Trunk 0.22.1.

```sh
rustup target add wasm32-unknown-unknown
cargo install trunk --version 0.22.1 --locked
npm ci
npm run dev
```

Приложение доступно по адресу [localhost:4260](http://127.0.0.1:4260).

### Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Сервер разработки |
| `npm run check` | Форматирование, тесты, Clippy и проверка каталога |
| `npm run build` | Сборка в `dist/` |
| `npm run verify:build` | Проверка файлов сборки и офлайн-ресурсов |

Push в `main` запускает проверки и публикацию в GitHub Pages через [workflow](.github/workflows/pages.yml).

## Структура проекта

- `crates/core` — модели данных, CSV/JSON и разбор результатов распознавания.
- `crates/web` — интерфейс, IndexedDB и обработка скриншотов.
- `data` — каталог существ и модов с источниками.
- `public` — стили, изображения и service worker.
- `scripts` — подготовка ресурсов, проверки и сборка.
